hyprmorph

Every window change is a swarm of pixels. A Hyprland plugin that turns window and workspace changes into a pixel morph, inspired by the page morph of a custom SteelSeries Arctis OLED daemon. Pixels break off, each with its own delay and arc, and fly into their new places.

Source on GitHubInstall

Demo: opening and closing a window, switching workspaces, fullscreen, and two drags.

What it does

Workspace switch

The content of the old desktop flies, pixel by pixel, into the content of the new one. Pixels that are the same on both stay put; new content streams in from the side you switch toward.

Open / close / resize / fullscreen

Windows that change are rebuilt from their own pixels: each pixel flies from its spot in the old box to the same spot in the new one. Only pixels that actually changed move.

Liquid-window drag

Drag a window (SUPER + mouse) and it becomes a fixed-size blob made of its own pixels, still laid out like the window, with a wobbling outline, a liquid stretch along the movement and a short trail. Drop it and it flies back into place.

Live destination

The target picture is captured every frame, so moving content (video, terminals) keeps updating during the morph.

Install

Built and tested against Hyprland 0.56 with the Lua config. Plugins are tied to the exact Hyprland version: rebuild after every Hyprland update.

git clone https://github.com/Guizzan/hyprmorph
cd hyprmorph
make            # builds hyprmorph-dev.so
make install    # copies it to hyprmorph.so (new inode, safe while Hyprland runs)

Load it from your Lua config and turn off Hyprland's own window and workspace animations, which the plugin replaces:

pcall(hl.plugin.load, os.getenv("HOME") .. "/path/to/hyprmorph/hyprmorph.so")
for _, leaf in ipairs({ "workspaces", "windowsIn", "windowsOut", "windowsMove", "fadeIn", "fadeOut" }) do
    hl.animation({ leaf = leaf, enabled = false })
end

Then log out and back in. Don't hot-swap the plugin in a running session (unloading it can crash Hyprland), and only run one of these effect plugins at a time.

Try it nested

Hyprland -c test/hyprland.lua
